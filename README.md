
# Python Password Vault

A beginner-friendly command-line password vault built with Python.

## Features

- Add account credentials
- View saved accounts with passwords hidden
- Search accounts by website
- Delete saved accounts
- Store data in JSON format
- Handle invalid input and malformed JSON

## Requirements

- Python 3
- No external packages required

## How to Run

```bash
python main.py
```

## Concepts Practiced

- Functions and dictionaries
- Lists and loops
- JSON file handling
- Exception handling
- User input and validation

## Security Notice

This project is a learning prototype. Passwords are
stored in plain-text JSON and are not encrypted.

Use fake credentials only. Do not use this version
to store real passwords.
